Connect

  1. Turn on Wi-Fi on the game console (Configuration → Network).
  2. Open Applications → Wi-Fi Transfer.
  3. Scan the QR code with your phone, or type the address shown (e.g. 192.168.1.23:8080) into a browser on a phone or PC on the same Wi-Fi.
  4. Enter the PIN shown on the game console.

SD cards

  • The tabs SD card 1 and SD card 2 show each card exactly as it is: every folder and file, with its size.
  • The line under the title shows each card's free and total space.
  • No second card? The SD card 2 tab says so. Turn the game console off, put the card in, then turn it on again.
  • MUOS on SD card 1 is muOS itself. Deleting or renaming anything in it asks first, because it can stop the game console from working.

Upload

  • Add games and Add a game folder (at the top of each SD card tab): games go to the right folder on that card by themselves, e.g. .gba → ROMS/GBA, .sfc → ROMS/SNES. Apps (.muxapp) go to that card's ARCHIVE; install them with Applications → Archive Manager.
  • Into a folder: open the folder, then tap Upload files or Upload a folder, or drag files onto the page on a PC.
  • Whole folders (e.g. a Dreamcast or PS1 game that has several files) keep their structure. A folder with a .gdi/.cdi goes to ROMS/DC by itself; for .cue/.bin games, open the right ROMS folder first. iPhones can't pick folders: create the folder, then upload its files.
  • If a file already exists, you're asked whether to replace it.
  • Keep the page open until uploads finish. Big files show their progress and speed.

Download

  • Tap the download icon on a file to save it.
  • On a folder, the download icon saves the whole folder as a .zip, e.g. a disc game or all your GBA games.
  • The download icon at the top saves the folder you're in as a .zip.
  • Tick several items and tap Download (.zip) to get only those, as one .zip.

Folders, rename, delete

  • Tap a folder's name to open it; the back arrow goes up one level. Each folder shows how many files it has and its size.
  • The new folder button creates a folder where you are. For a disc game, use the game's name, e.g. My Game.
  • Rename and delete are the icons on each row. To delete several at once, tick them (or Select all), then tap Delete. Delete always asks first and can't be undone.
  • To move or copy, tick items and tap Move or Copy, choose the folder, on either SD card, and tap Move here or Copy here.

Search

  • Type part of a name in the search box at the top: it searches both SD cards. Capital letters don't matter; with several words, a name must contain all of them.
  • Each result shows where it is. Open its folder, download it, or tick results and delete them.
  • The back arrow closes the search.

Full backup of SD card 1

A complete copy of SD card 1, the card muOS starts from: muOS, settings, games, saves, everything. Keep it safe in case the card gets corrupted or lost.

  1. Use a PC with enough free space (a phone is usually too small), and plug in the game console.
  2. Below the SD card tabs, tap Start backup in Full backup of SD card 1.
  3. Your browser downloads muOS-SD-backup-DATE.img.gz. Empty space isn't sent, so it's about as big as your data. It takes roughly 1 hour per 10 GB.
  4. Keep the page and the game console on. Uploads and changes are paused while the backup runs. To stop it, tap Cancel backup (or press B twice on the game console), then delete the incomplete file.
  5. When the download finishes without an error, the backup is complete.

For your own use only: the backup holds your games, saves and BIOS files, so keep it private and don't share it.

Safari on a Mac: turn off Settings → General → Open “safe” files after downloading, or Safari unpacks the file.

Restore a backup to a new card

The new card must be the same size or bigger than the old one. Everything on the new card is replaced.

Windows, with Rufus

  1. Put the new card in the PC and open Rufus (rufus.ie).
  2. Device: the SD card. Check it's the right one.
  3. SELECT: the .img.gz backup file (no need to unpack it).
  4. Press START, confirm, and wait until it says READY.
  5. If Windows asks to format the card afterwards, press Cancel.

Mac or Linux, with balenaEtcher

  1. Open balenaEtcher (etcher.balena.io), choose Flash from file and pick the .img.gz.
  2. Select target: the SD card, then Flash!

Put the card in the game console and turn it on: it starts exactly as it was when you made the backup.

Only need a few files back? Unpack the .img.gz (e.g. with 7-Zip), then mount the .img on Windows with OSFMount: the games partition opens like a USB drive.

On the game console

  • X keeps Wi-Fi Transfer running in the background: go back to the muOS menu or play a game while the page keeps working. It stops after 15 minutes without activity; open Wi-Fi Transfer again to see it on the screen.
  • B stops Wi-Fi Transfer and quits. If something is still transferring, press it again within 3 seconds.
  • Y makes a new PIN and logs everyone out.
  • SELECT changes the language of the game console's screen.
  • It stops by itself after 15 minutes without activity; A starts it again.
  • The game console stays awake while a phone or PC is connected.

Security

  • The page only works while Wi-Fi Transfer is open or running in the background, only on your home network, and only with the PIN.
  • 5 wrong PINs lock that device out for a minute.
  • It shows everything on your SD cards, including muOS's own files in MUOS: be careful there.
  • Don't use it on public Wi-Fi.

Problems

  • The page doesn't open: the phone or PC must be on the same Wi-Fi as the game console (not mobile data, not a guest network).
  • “Wi-Fi is off” on the game console: turn on Wi-Fi in muOS; the transfer starts once it's connected.
  • New games don't show up in muOS: quit Wi-Fi Transfer with B, then open the system's folder again.
  • Upload stopped: the phone may have locked its screen. Keep the page open and try again.
  • The card's used space is much bigger than its folders: an interrupted copy can leave space marked as used. Put the card in a PC or Mac and run a disk check (Mac: Disk Utility → First Aid; Windows: Properties → Tools → Check).
  • Something else: email feedback@pocketkode.com and tell us what you did and what you saw.

Update available

    Privacy: what Wi-Fi Transfer sends

    Your files go only between this game console and your own phone or PC, the one where you open this page and save them. They never go over the internet, and Wi-Fi Transfer never reads or sends them anywhere else.

    For updates it reads the latest release on GitHub (you can turn this off below). It sends nothing about you or the game console.

    No ads, no analytics, no tracking. More on pocketkode.com/privacy.
